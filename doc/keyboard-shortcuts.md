## General Shortcuts

| Shortcut | Windows/Linux | macOS | Description |
|----------|---------------|-------|-------------|
| Search | `Ctrl + F` | `Cmd + F` | Open the search window |
| Select All | `Ctrl + A` | `Cmd + A` | Select all items in the active container |
| Copy | `Ctrl + C` | `Cmd + C` | Copy selected items to clipboard |
| Cut | `Ctrl + X` | `Cmd + X` | Cut selected items to clipboard |
| Paste | `Ctrl + V` | `Cmd + V` | Paste items from clipboard |
| Undo | `Ctrl + Z` | `Cmd + Z` | Undo the last action |
| Close Window | `Ctrl + W` | `Ctrl + W` | Close the active window |

---

## File Management

| Shortcut | Windows/Linux | macOS | Description |
|----------|---------------|-------|-------------|
| Delete | `Delete` | `Ctrl + Backspace` or `Cmd + Backspace` | Move selected items to Trash |
| Permanent Delete | `Shift + Delete` | `Option + Cmd + Backspace` | Permanently delete selected items (bypasses Trash) |
| Open | `Enter` | `Enter` | Open the selected item(s) |
| Open in New Window | `Ctrl + Enter` | `Cmd + Enter` | Open the selected item(s) in a new window |

## Navigation

### Arrow Key Navigation

| Shortcut | Description |
|----------|-------------|
| `↑` (Up Arrow) | Navigate to the item above |
| `↓` (Down Arrow) | Navigate to the item below |
| `←` (Left Arrow) | Navigate to the item on the left |
| `→` (Right Arrow) | Navigate to the item on the right |
| `Shift + Arrow Keys` | Extend selection in the arrow direction |

### Quick Item Search

When you start typing letters or numbers (without any modifier keys), Puter will search for items matching your input in the active container. This allows for quick navigation to files and folders by name.

## Window Management

| Shortcut | Description |
|----------|-------------|
| `Esc` | Close dialogs, alerts, context menus, or the Launch Popover |
| `Ctrl + W` | Close the active window |

---

## Context Menu Navigation

When a context menu is open:

| Shortcut | Description |
|----------|-------------|
| `↑` (Up Arrow) | Move to the previous menu item |
| `↓` (Down Arrow) | Move to the next menu item |
| `→` (Right Arrow) | Open submenu (if available) |
| `←` (Left Arrow) | Close submenu and return to parent menu |
| `Enter` | Activate the selected menu item |
| `Esc` | Close the context menu |

## Search

### Search Window Navigation

When the search window is open:

| Shortcut | Description |
|----------|-------------|
| `↑` (Up Arrow) | Navigate to the previous search result |
| `↓` (Down Arrow) | Navigate to the next search result |
| `Enter` | Open the selected search result |
| `Esc` | Close the search window |

---

## Launch Menu Navigation

When the Launch Menu (Start menu) is open:

| Shortcut | Description |
|----------|-------------|
| `↑` (Up Arrow) | Navigate up in the app grid |
| `↓` (Down Arrow) | Navigate down in the app grid |
| `←` (Left Arrow) | Navigate left in the app grid |
| `→` (Right Arrow) | Navigate right in the app grid |
| `Enter` | Launch the selected application |
| `Esc` | Close the Launch Menu |

## Platform-Specific Notes

### Windows/Linux
- Use `Ctrl` as the primary modifier key
- `Delete` key moves items to Trash
- `Shift + Delete` permanently deletes items

### macOS
- Use `Cmd` (⌘) as the primary modifier key
- `Ctrl + Backspace` or `Cmd + Backspace` moves items to Trash
- `Option + Cmd + Backspace` permanently deletes items

---

## Tips

1. **Quick Navigation**: Start typing a file or folder name to quickly jump to it
2. **Multi-Select**: Hold `Shift` while using arrow keys to select multiple items
3. **Keyboard-First Workflow**: Use `Tab` to navigate between different areas of the interface
4. **Context Menus**: Right-click or use the context menu key to access additional options
